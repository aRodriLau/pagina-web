# Microsoft (MSFT)

## In breve
- **Cosa fa:** software (Windows, Office), cloud **Azure**, assistente AI Copilot, partner di OpenAI.
- **Livello filiera AI:** cloud / utilizzatore: vende AI ai clienti e compra enormi quantità di chip.
- **Dove si compra / valuta:** Nasdaq, in dollari (su Trade Republic la vedi in €).

## Perché è interessante
- Guadagna dall'AI tramite abbonamenti e cloud, non solo dalla vendita di hardware.
- Ricavi molto diversificati: è una delle aziende più stabili del mondo.

## Rischi principali
- Spende cifre enormi in data center: se l'AI rende meno del previsto, gli investitori la puniscono.
- Si muove poco: ottima per imparare, meno "emozionante".
- È già tra le prime posizioni del tuo FTSE All-World.
